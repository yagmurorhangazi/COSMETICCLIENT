✨ Lumière 

Lumière Store, kozmetik sektörüne yönelik geliştirdiğim modern ve dinamik bir web uygulamasıdır.

Projenin frontend tarafında Angular, backend tarafında ise ASP.NET Core Web API kullanarak frontend ve backend katmanlarını birbirinden bağımsız şekilde geliştirdim.

🎯 Projenin Amacı

Lumière Store ile modern, sade ve kullanıcı dostu bir kozmetik platformu oluşturmayı hedefledim.

Uygulamada ürünlerin ve kategorilerin yönetilebildiği, kullanıcıların ürünleri filtreleyip sıralayabildiği ve mağaza hakkında yorum bırakabildiği dinamik bir yapı oluşturdum.

🚀 Öne Çıkan Özellikler
Ürün listeleme
Kategori bazlı filtreleme
Fiyat aralığına göre filtreleme
Fiyata ve isme göre ürün sıralama
Dinamik ürün görselleri
Ürün ekleme, silme ve güncelleme
Kategori ekleme, silme ve güncelleme
Müşteri yorumları ve puanlama
Admin paneli
Responsive kullanıcı arayüzü
REST API üzerinden dinamik veri alışverişi

🏗️ Proje Mimarisi

Frontend ve backend katmanlarını birbirinden ayırarak API tabanlı bir yapı oluşturdum.

Bu yapı sayesinde Angular uygulaması, backend tarafındaki API üzerinden ürün, kategori ve yorum verilerine erişebiliyor.

🔍 Dinamik Ürün Yönetimi

Kullanıcılar ürünleri:

Kategoriye göre
Maksimum fiyata göre
Fiyat sıralamasına göre
İsme göre

filtreleyip sıralayabiliyor.

Admin paneli üzerinden ise ürün ve kategori işlemleri gerçekleştirilebiliyor.

💬 Yorum Sistemi

Projede kullanıcıların mağaza hakkındaki düşüncelerini paylaşabilmesi için dinamik bir yorum sistemi geliştirdim.

Kullanıcılar:

Ad soyad
Profil görseli
Yorum
Puan

bilgilerini girerek değerlendirme oluşturabiliyor.

👨‍💻 Geliştirme Süreci

Bu projeyi M&Y Yazılım Eğitim Akademi Danışmanlık bünyesinde, Erhan Gündüz hocamın rehberliğinde geliştirdim.

Proje sürecinde özellikle Angular, ASP.NET Core Web API, REST API entegrasyonu, CRUD işlemleri, Entity Framework Core ve dinamik veri yönetimi konularında kendimi geliştirme fırsatı buldum.
